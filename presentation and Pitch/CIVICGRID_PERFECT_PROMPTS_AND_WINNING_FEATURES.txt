FEATURE 1: SATELLITE & COMPUTER VISION INGESTION (SENTINEL-2 / POTHOLE & FLOOD DETECTION)
----------------------------------------------------------------------------------------------------
• Concept: Ingest multi-spectral Sentinel-2 satellite imagery tiles and citizen road photos. Use a lightweight
  MobileNetV3 / ResNet-18 model to detect road pavement degradation, flood water inundation (NDWI),
  and dry reservoirs.
• Python Implementation (`backend/services/vision_service.py`):
```python
import numpy as np

class VisionService:
    @staticmethod
    def analyze_satellite_tile(band_green: np.ndarray, band_nir: np.ndarray):
        """
        Calculates Normalized Difference Water Index (NDWI) to detect flood inundation.
        NDWI = (Green - NIR) / (Green + NIR)
        """
        denom = band_green + band_nir
        denom[denom == 0] = 1e-9
        ndwi = (band_green - band_nir) / denom
        flood_inundation_percentage = float(np.mean(ndwi > 0.3) * 100)
        severity = "Critical" if flood_inundation_percentage > 35 else "Medium"
        return {
            "flood_inundation_pct": round(flood_inundation_percentage, 2),
            "detected_water_anomaly": flood_inundation_percentage > 20,
            "vision_severity": severity
        }
```

FEATURE 3: CRYPTOGRAPHIC MERKLE-TREE AUDIT LINEAGE (TAMPER-PROOF LEDGER)
----------------------------------------------------------------------------------------------------
• Concept: Every batch of citizen complaints and every SCIP knapsack optimization decision is hashed
  into a SHA-256 Merkle Tree. Policymakers cannot secretly alter scores or reallocate budgets without
  invalidating the cryptographic root hash.
• Implementation (`src/lib/merkleAudit.ts`):
```typescript
import { createHash } from 'crypto';

export class MerkleAudit {
  public static computeRoot(records: any[]): string {
    const leaves = records.map(r => 
      createHash('sha256').update(JSON.stringify(r)).digest('hex')
    );
    let currentLevel = leaves;
    while (currentLevel.length > 1) {
      const nextLevel: string[] = [];
      for (let i = 0; i < currentLevel.length; i += 2) {
        const left = currentLevel[i];
        const right = currentLevel[i + 1] || currentLevel[i];
        const combined = createHash('sha256').update(left + right).digest('hex');
        nextLevel.push(combined);
      }
      currentLevel = nextLevel;
    }
    return currentLevel[0] || '00000000000000000000000000000000';
  }
}
```
